🏛️ MP Game Udaan 2026 Submission Official Theme: JUGAAD
Conceptualized & developed from scratch for the "Kuch na kuch kar lenge" spirit. An indigenous indie adventure capturing the comedic, resourceful soul of Madhya Pradesh street life.
🌐 Custom 3D WebGL Engine (Three.js) Zero 3D Asset Imports
100% Procedural 3D Models: No pre-made external .gltf or .fbx models used! Chetak Scooter, Gau Mata, Chacha, Chachi, Sheesh Mahal Mandap, Excavation Trench, and Jugaad items are handcrafted using pure geometric primitives, hierarchical matrix pivots, and custom PBR shader materials.
⚡ Custom Deterministic Physics Pipeline Smooth 60 FPS
Built with a custom lightweight AABB (Axis-Aligned Bounding Box) + Dynamic Radial Circle Collider system. Includes realistic 2-meter deep trench gravity tumbling, bridge snap physics, and cow roadblock avoidance with zero external physics engine overhead.
🔊 Procedural Sound Synthesis Pure Web Audio API
Real-time frequency-modulated oscillators dynamically generate the vintage 2-stroke Chetak engine sound directly mapped to scooter throttle speed and RPM. Custom procedural impulse responses for metal crashes, horn, brick thud, and water splash.
🧠 5-Stage Finite State Machine (FSM) Modular Architecture
State machine handles: Opening Comic Cutscene ➔ Stage 1: Toota Phone Jugaad ➔ Stage 2: Phatte Ka Pul ➔ Stage 3: Gau Mata Feeding ➔ Stage 4: Laal Eent Kickstand ➔ Victory Mandap Entrance. Features 3-disaster life tracking, countdown timer, and persistent localStorage telemetry.
